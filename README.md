# Formulario Igreja Lagoinha Matriz

# Solicitação

Criar um formulário para receber informações de visitantes ou novos membros que foram a algum dos cultos do dia. 

Com essas informações preenchidas no formulário, o formulário irá iniciar um fluxo para o setor responsável por atendimento a novos membros, assim eles terão os dados da pessoa e poderão entrar em contato para falarem sobre os assuntos da igreja. 

# Solução

Criei um formulário utilizando HTML5, CSS3 e JavaScript para que ao lerem o QRCode colado no quadro da igreja a pessoa possa preencher seus dados e assim iniciar um fluxo, o formulário está integrado via API com o Workflow do ArqGED.

O formulário foi criado de forma responsiva e pensado na praticidade de preenchimento do usuário, sendo assim, é possível preencher com Smartphone, tablet e destktop.
